# acousto-mechano-neuron has moved → **ultraneuron**

### ➡️ New home: **https://github.com/pinton-lab/ultraneuron**

The framework described in the accompanying *Journal of Neural Engineering*
manuscript — an open-source pipeline predicting ultrasound neuromodulation, from
a transcranial acoustic field to per-voxel neural firing maps registered to
anatomy — is developed and released as **`ultraneuron`**.

If you arrived here from the paper's **Data Availability** statement (which cites
this repository under its former name, `acousto-mechano-neuron`), everything —
the framework, the reproduction scripts, the validation-report pipeline, and the
test suite — now lives at:

## 👉 https://github.com/pinton-lab/ultraneuron

- **Install / import** as `ultraneuron`
- **License:** Apache-2.0
- **Citation:** see `CITATION.cff` in the [ultraneuron](https://github.com/pinton-lab/ultraneuron) repository

*This repository is retained only to keep the paper's original link working; it
is no longer developed here.*
